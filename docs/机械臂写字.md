本机输出位置：

`/home/robot/coppeliasim/machine_learning/model/outputs/brush_mapping_20261023/gong_initial_full_model_trial/runs/`

每次运行新建一个目录；jx 原始记录下载到其中的 `remote_evidence/`。原始力、控制器反馈及实际程序会保留，不仅保存统计信息。

| 返回状态 | 含义 |
| --- | --- |
| `offline_preview_passed` | 离线预览通过，未运动 |
| `preflight_passed_no_motion` | 当前阶段预检通过，尚不能据此认定实际书写完成 |
| `completed_buffered_program` | 本次有限运动程序完成，并核对了最终位姿；墨迹质量需另行观察或测量 |
| `stopped_on_error` | 本次运行失败或被保护停止；结合 `motion_sent`、错误和原始记录判断已执行到哪里 |

实机命令可能先输出预检通过，再输出执行失败。应查看最终结果，不能只看中间一条预检通过信息。
