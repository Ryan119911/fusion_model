## 2. 坐标与模型语义：不要误用

- 源 `x/y` 是数据集源坐标，**不是 mm、不是 128 画布像素、不是 Base XYZ**。
- 源 `z` 是模型 H，单位 mm；不是 TCP Base Z、测得的压力或真实毛束压入量。
- `alpha/beta/gamma` 为 rad；不是直接可发给 UR 的欧拉角。
- 源 gamma 是原生画布（y 下）绝对角；整理文件同时保留 `source_gamma_absolute_canvas_rad`、`gamma_local_rad`、`gamma_absolute_paper_rad`。转换一次即可，不能再次叠加切线。
- 整理表 `paper_x_m/paper_y_m` 为历史纸面坐标，单位 m，x 右/y 上；尚未加入当前试写平移。既有历史画布尺度为 `0.29/96 m/px`，不使用 ROS 渲染缩放改字号。
- `state=0/1/2` 表示一笔起点/笔身/终点，不证明笔已离纸或 H=0。
- 模型插值、法兰 MoveL 与姿态 SLERP、真实毛束接触轨迹是不同对象；检查必须针对最终程序实际使用的插值。
