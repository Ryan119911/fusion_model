# 毛笔 H、α、β 长线标定代码使用

更新：2026-11-06。基于 Gülzow 的连续下压扫描和 Karimov 的侧视观测，面向固定方向的真实毛笔标定。代码一次执行一条线，不自动批量增加下压或连续运行下一条。

入口为 `tools/brush_longline_calibration.py`。规划、图像处理、找零估计和模型拟合在 MU 离线运行；相机检查与机械臂接口在设备所在主机运行。本文命令中的相对路径均相对本仓库根目录，输出目录必须是新目录。

## 已实现的内容和验证边界

- 生成 `zero/h/alpha/beta/joint` 长直线。单变量及联合输入可在一条线内连续变化，也支持自定义节点和平滑过渡。
- 使用纸面固定轴约定 `R = Rot(v,beta) @ Rot(u,alpha) @ R0`，补偿自然笔尖到工具原点的偏移。旧模型角度不直接等同于执行角。
- 保存输入 CSV、位姿规划和 SVG 预览。示例几何仅用于软件检查，不能直接进入实机预检。
- 复用现有 `brush_buffered_motion` 与 `brush_buffered_guard`，执行前保留完整路径审计、当前起点绑定、姿态相关空载参考和控制器看门狗检查。
- 相机支持 OpenCV USB/RTSP 或 ROS `sensor_msgs/Image`。ROS 相机可配置触发服务。同步记录侧视视频、逐帧时间、位姿反馈和原始力。
- 写前、写后拍照，测量墨迹横截面宽度和中心偏移。支持固定相机单应变换，也支持手眼标定结合两次实际拍照位姿。
- 从侧视轮廓生成投影间隙，输出视觉接触候选及高度区间。该结果不会自动覆盖当前纸面，也不把首次出墨当作首次接触。
- 使用有可靠输入对应的实测数据拟合三变量二次响应；保留独立验证，输出误差和输入域外标记。

本轮完成的是软件测试和合成数据验证，未连接机器人、未触发真实相机、未发送运动。实机通讯、相机服务名、当前几何和完整真实笔触效果仍需在现场验证。完整运行证据按实际输出记录，不将一次软件测试写为实机成功。

## 1. 先检查运行环境

MU 已检查可用的环境是系统 Python 加 `PYTHONNOUSERSITE=1`，避免用户目录的 NumPy 2 与系统 OpenCV 冲突：

```bash
PYTHONNOUSERSITE=1 /usr/bin/python3 -B tools/brush_longline_calibration.py --help
```

其他主机可在独立环境中准备 `requirements-brush-calibration.txt` 的依赖。jx 的机械臂接口需要沿用现有 ROS、UR10 和 robotpkg 环境，不在 ROS 系统环境中直接升级 NumPy/OpenCV。硬件入口另需已有 `probe_paper_height.py`、`calibrate_pen_tcp.py` 及其路径审计依赖。

jx 的硬件命令先在同一个终端加载已有 ROS 环境：`source /opt/ros/humble/setup.bash`。硬件适配器会查找该用户的 `.dsh-analysis`、明确传入的机器人 scripts 目录，以及与当前 Python 版本对应的现有 robotpkg site-packages。离线命令不需要 ROS。

无需任何设备即可检查整条分析链：

```bash
PYTHONNOUSERSITE=1 /usr/bin/python3 -B tools/brush_longline_calibration.py demo \
  --output outputs/longline_demo_01
```

输出明确标为 `synthetic_demo`，只验证数据、拟合和独立预测接口，不代表真实毛笔标定。

## 2. 建立实验配置

```bash
PYTHONNOUSERSITE=1 /usr/bin/python3 -B tools/brush_longline_calibration.py init \
  --output outputs/longline_session/experiment.json
```

也可以从你明确选择的现有候选导入纸面轴、纸面基点、笔尖偏移和基准姿态：

```bash
PYTHONNOUSERSITE=1 /usr/bin/python3 -B tools/brush_longline_calibration.py init \
  --candidate outputs/brush_mapping_20261027/gong_current_mount_trial_cal28/candidate.PREVIEW_ONLY.json \
  --output outputs/longline_session/imported_experiment.json
```

该历史路径只用于说明导入格式；不自动断言安装、纸面或零点仍然有效。确认当前几何后，在自己的配置中填写：

| 配置项 | 应填写的真实内容 |
| --- | --- |
| `geometry.paper_origin_base_m` | 当前纸面基点，机器人基坐标，米 |
| `paper_u_base/paper_v_base/paper_normal_base` | 右手正交纸面轴；本轮沿 +u 写直线 |
| `tip_tool_m` | 未接触几何笔尖相对 tool0 的偏移，米 |
| `baseline_rotation_rad` | 基准 tool0 旋转向量，rad |
| `paper_bounds_uv_mm` | 当前已测纸张范围 `[umin,umax,vmin,vmax]` |
| `geometry_status` | 实际几何确认后为 `measured_current_setup`；仅改此文字不构成测量 |
| `motion.start_uv_mm/length_mm` | 当前空白区域起点与长度 |
| `inputs.H_mm/alpha_deg/beta_deg` | 经现场确定的输入上下界及基准值，不照搬示例或旧模型范围 |
| `motion.speed_mm_s` | 名义自然笔尖平移速度；真正速度以反馈重建为准 |
| `motion.force_stop_n` | 本次明确选用的力增量门限；示例沿用当前项目 100 N，不自动改动生产门限 |

示例的下压、角度、长度与速度均为软件模板，没有实机验证。程序会拒绝越出声明纸张范围、角速度过高、所需工具速度超过现有 30 mm/s 上限等候选。

## 3. 生成一条长线

```bash
PYTHONNOUSERSITE=1 /usr/bin/python3 -B tools/brush_longline_calibration.py plan \
  --config outputs/longline_session/experiment.json \
  --kind h --trial-id H01 --repeat-group H_repeat \
  --output outputs/longline_session/H01_plan
```

`--kind` 选择：

| 值 | 行笔中的输入 |
| --- | --- |
| `zero` | 固定姿态，由悬空逐渐下降，固定下降／平移比例 |
| `h` | 只改变 H，角度固定 |
| `alpha` | 只改变 α，H 和 β 固定 |
| `beta` | 只改变 β，H 和 α 固定 |
| `joint` | 三者按不同顺序变化，避免始终同步同增 |

输出 `plan.json`、`commanded_inputs.csv`、`input_preview.svg`，终端显示名义悬空起点。只生成文件，不访问设备。

更换纸面空白位置时修改 `start_uv_mm`，保留独立 trial_id。每组重复使用相同曲线但独立准备笔态。最终验证用 `--split holdout`，修改波形后生成新的实验编号，不把同一条线的点随机拆成训练和测试。

自定义波形：在配置顶层增加 `knots`，节点字段为 `fraction/H_mm/alpha_deg/beta_deg`。fraction 必须严格从 0 到 1 递增。普通扫描使用五次平滑插值；找零使用线性插值且保持姿态固定。生成不同联合序列时调整节点，不重复使用同一模板充当独立新序列。

## 4. 配置并单独检查相机

复制并填写 `examples/brush_longline_cameras.json`。其中设备名、ROS 主题、服务名、服务类型都是配置入口，需对应实际设备。示例 ROS 服务名和类型没有本次现场验证。

```bash
PYTHONNOUSERSITE=1 /usr/bin/python3 -B tools/brush_longline_calibration.py camera-check \
  --cameras outputs/longline_session/cameras.json --duration-s 2 \
  --output outputs/longline_session/camera_check_01
```

该命令只调用相机，不导入机械臂接口、不发运动。检查输出 `before.png/after.png/tip_before.png/side.avi/side_frames.jsonl`：

- 侧视应看见笔尖、纸面和所需变形区；背景要与毛束有足够对比。
- 俯视或斜视应覆盖完整的待测区域，机器人或夹具不能长期遮挡墨迹。
- 时间日志保存主机单调时钟及可获得的 ROS 源时间。不把相机帧到达时间宣称为精确硬件同步曝光时间。

若使用手上相机，写前和写后的相机位姿不同，后处理要使用两次实际位姿与手眼参数。若写线姿态下看不全纸面，应按现有拍照流程另采图和真实拍照位姿，再交给 `measure`；本入口不自动规划额外拍照转移。

## 5. 准备姿态相关的空载力参考

角度变化时不能把单个姿态的零力向量用于整条路线。可使用本入口采集静止悬空参考，再做独立留出检查；采集命令不会移动到目标姿态，也不会清零传感器。

在 jx、当前已经稳定悬空且姿态已确认的情况下，每个姿态分别运行：

```bash
PYTHONNOUSERSITE=1 /usr/bin/python3 -B tools/brush_longline_calibration.py record-air \
  --robot-scripts /home/jx/UR10/scripts --unloaded-confirmed \
  --output outputs/longline_session/air_A01
```

在实际计划姿态范围内采集多个独立姿态，包含两角联合组合和位置范围，另外保留独立检查姿态。不能把刚接触纸面的状态标为悬空。已有无运动的位姿/力采集工具也可提供参考，但不能用历史过期记录冒充新采集。

以下是命令结构，实际文件数按采集记录填写：

```bash
PYTHONNOUSERSITE=1 /usr/bin/python3 -B tools/brush_longline_calibration.py fit-force \
  --samples outputs/longline_session/air_A01/sample.json \
            outputs/longline_session/air_A02/sample.json \
            outputs/longline_session/air_A03/sample.json \
            outputs/longline_session/air_A04/sample.json \
  --holdout outputs/longline_session/air_V01/sample.json \
            outputs/longline_session/air_V02/sample.json \
  --maximum-error-n 1 --maximum-translation-m 0.1 \
  --output outputs/longline_session/force_fit_01
```

误差限与位置域应根据实际采集确定，示例参数不是本次验证结论。模型至少要求仿射基底可辨识，检查留出误差、参考姿态覆盖和 30 分钟新鲜度。结果 `passed=false` 时不会进入运动。不会通过重新拟合把旧采样时间刷新为当前时间。

该拟合是局部姿态空载参考，留出静态结果不证明动态接触力已被精确测量。初次运行仍需查看原始力和误差，不把其结果当作毛笔 H 的真值。

## 6. 实机只读预检，然后执行一条

将代码、配置及计划放到 jx 的同一仓库中。机器人先处于计划显示的悬空起点；此代码不会自动从未知当前位置连接过去。用已有的当前安装看门狗硬件验证记录，并执行只读预检：

```bash
PYTHONNOUSERSITE=1 /usr/bin/python3 -B tools/brush_longline_calibration.py prepare \
  --plan outputs/longline_session/H01_plan/plan.json \
  --force-reference outputs/longline_session/force_fit_01/force_reference.json \
  --watchdog /home/jx/UR10/outputs/gong_1mm_continuous_20261016/watchdog_validation_v2.json \
  --guard-host 192.168.1.10 --robot-scripts /home/jx/UR10/scripts \
  --output outputs/longline_session/H01_prepared
```

`--guard-host` 必须是机器人能回连到的本机地址；上述地址沿用项目示例，不代替网络现场检查。prepare 读取机器人当前状态，调用现有路径审计并导出完整程序，不发运动、不触发相机。若原看门狗记录与当前编译器哈希不一致，需按现有流程重新验证，不能手改哈希。

先查看准备结果：

```bash
PYTHONNOUSERSITE=1 /usr/bin/python3 -B tools/brush_longline_calibration.py run \
  --prepared outputs/longline_session/H01_prepared/prepared.json \
  --output outputs/longline_session/H01_preview
```

没有 `--execute` 时完全离线，不触发相机、不访问机械臂。真正执行命令为：

```bash
PYTHONNOUSERSITE=1 /usr/bin/python3 -B tools/brush_longline_calibration.py run \
  --prepared outputs/longline_session/H01_prepared/prepared.json \
  --cameras outputs/longline_session/cameras.json \
  --robot-scripts /home/jx/UR10/scripts --execute \
  --output outputs/longline_session/H01_run
```

run 先检查文件、参考新鲜度和相机，再复用现有守护器执行一条完整路线。写前笔尖、连续侧视、真实反馈和写后图归档到同一个 trial_id。失败时保留已取得数据，不自动重试、抬笔或转入下一条。`RESULT.json` 区分是否实际发送过运动和是否完整完成。

**本轮未执行以上硬件命令。** 其现场验证状态仍为待测试，不是成功发布或完整实机成功。

## 7. 从图像得到墨迹测量

固定相机先填写 `examples/brush_longline_ink_calibration.json` 中的实际像素到纸面毫米变换、ROI 和尺度。此模式输入图需已完成镜头畸变校正。

```bash
PYTHONNOUSERSITE=1 /usr/bin/python3 -B tools/brush_longline_calibration.py measure \
  --before outputs/longline_session/H01_run/before.png \
  --after outputs/longline_session/H01_run/after.png \
  --feedback outputs/longline_session/H01_run/controller_feedback.jsonl \
  --plan outputs/longline_session/H01_run/plan.json \
  --calibration outputs/longline_session/ink_calibration.json \
  --output outputs/longline_session/H01_measure
```

输出墨迹掩膜、正射图和 `features.csv`。默认只测图像，不把最终墨迹某位置直接认作同一位置机器人刚刚施加的输入。只有实际检查了沿线偏移和输入对应，才填写 `input_alignment.verified=true` 及证据说明；未经确认的输入对应不能进入拟合。`ink_to_nominal_tip_offset_mm` 定义为“墨迹位置加此偏移得到对应名义笔尖位置”，不能靠随意平移减小模型误差。

反馈保持时间顺序处理，不按位置重新排序。默认忽略相对上个保留样本前进不足 0.05 mm 的抖动，并记录忽略数量；回退超过 0.2 mm 时拒绝关联。这两个毫米参数可在测量配置中调整，应结合实际位置噪声和所需分辨率确定。

手上相机使用 `mode="handeye"`，提供真实 `camera_info`（k、d、width、height、distortion_model 等）和 4×4 `tool0_from_camera`，并在同一命令中加入：

```text
--before-pose outputs/longline_session/H01_run/before_pose.json
--after-pose outputs/longline_session/H01_run/after_pose.json
```

两张图分别去畸变并按各自拍照位姿映射到纸面。不能共用一张未经修正的像素—毫米矩阵处理移动相机的两张照片。ROI 必须在两次视野内，且与其他墨迹隔离。

## 8. 侧视与自动零点候选

先填写 `examples/brush_longline_side_calibration.json`：仅包含笔尖毛束的 ROI、纸面在图像中的直线、实际毫米尺度及轮廓阈值。直线 ax+by+c 在纸面上方为正。该方法要求清晰侧视轮廓，不能把夹具、阴影或桌边当作毛笔。

```bash
PYTHONNOUSERSITE=1 /usr/bin/python3 -B tools/brush_longline_calibration.py side \
  --video outputs/longline_session/Z01_run/side.avi \
  --frames outputs/longline_session/Z01_run/side_frames.jsonl \
  --calibration outputs/longline_session/side_calibration.json \
  --output outputs/longline_session/Z01_side

PYTHONNOUSERSITE=1 /usr/bin/python3 -B tools/brush_longline_calibration.py zero \
  --side-csv outputs/longline_session/Z01_side/side_features.csv \
  --feedback outputs/longline_session/Z01_run/controller_feedback.jsonl \
  --plan outputs/longline_session/Z01_run/plan.json \
  --gap-threshold-mm 0.1 --consecutive-frames 3 \
  --output outputs/longline_session/Z01_zero
```

Z01 应为 `--kind zero` 的实际找零实验。0.1 mm 是命令示例，应根据尺度与可见误差确定。输出记录最后明确离纸与最早持续接触候选的区间、纸面法向修正候选和来源配置哈希。遮挡、没有先验离纸帧或时间缺口时拒绝给出零点。结果为视觉接触候选，检查重复性后再采用，不把阈值接触等同于无变形真值。

## 9. 拟合与独立预测

完成三变量独立与联合变化，汇集已经确认输入对应的特征 CSV：

```bash
PYTHONNOUSERSITE=1 /usr/bin/python3 -B tools/brush_longline_calibration.py fit \
  --csv outputs/longline_session/H01_measure/features.csv \
        outputs/longline_session/A01_measure/features.csv \
        outputs/longline_session/B01_measure/features.csv \
        outputs/longline_session/J01_measure/features.csv \
  --output outputs/longline_session/response_01
```

文件列表按实际数据扩展。该命令要求三变量有独立变化且二次设计矩阵满秩；只有一条 H 扫描或三变量始终同步变化时，会拒绝宣称联合标定完成。输出模型包含训练实验编号、重复组、输入域和训练残差；训练残差不等于独立验证。

```bash
PYTHONNOUSERSITE=1 /usr/bin/python3 -B tools/brush_longline_calibration.py predict \
  --model outputs/longline_session/response_01/model.json \
  --csv outputs/longline_session/V01_measure/features.csv \
  --output outputs/longline_session/V01_predict
```

用未参与拟合的新实验计算笔宽、中心偏移误差。`metrics.json` 标明是否出现训练实验／重复组，并报告域内 MAE、RMSE 和 95% 绝对误差。域外预测单独标记，不与域内指标混合。

本版本建立固定速度、固定方向下的静态墨迹响应。若同一输入在上行、下行历史下有明显不同，应缩小到稳定段、减慢变化或进一步引入动态模型，不能把静态结果写成完整动态接触模型。
